# Prompt del icon set premium

Lucas adjunta la imagen de estilo y corre un prompt por ícono: el bloque STYLE queda igual y solo se cambia la línea
SUBJECT. El ícono se guarda en `PACKS/ICONOS/` con el nombre de archivo de la tabla, así el editor lo encuentra.

## Prompt (una generación por ícono)

```
STYLE: Match the attached reference image exactly — same rendering technique, materials, lighting direction,
color palette, level of detail and camera angle. Single premium 3D icon, centered, filling about 80% of the frame,
slight three-quarter view. Clean, glossy, high-end product-render look. No text, no letters, no numbers, no logos,
no watermark. Isolated on a fully transparent background (PNG with alpha); if transparency is not supported, use a
flat solid pure white background with no floor, no cast shadow and no gradient. Square 1:1, 2048x2048.

SUBJECT: <paste one line from the list below>
```
