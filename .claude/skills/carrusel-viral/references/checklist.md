# Checklist antes de entregar

Mirando cada PNG (no el código):

- [ ] La portada se entiende en un segundo y tiene su `[clave]`.
- [ ] Cada lámina tiene una sola idea y no pasa de ~25 palabras.
- [ ] Ninguna lámina tiene texto cortado ni fuera de los márgenes (96 px laterales).
- [ ] La `[clave]` se lee: en color de marca, o con marcador si el acento no contrasta.
- [ ] Texto sobre el fondo de acento: contraste ≥ 4,5:1 (`textoAcento`).
- [ ] Alternan tipos y fondos; no hay tres láminas iguales seguidas.
- [ ] El contador (`NN / NN`) y la flecha están; la última lámina no lleva flecha.
- [ ] Ninguna cifra, caso o cita fue inventada.
- [ ] El cierre pide una sola acción.
- [ ] Se entiende leyendo solo las portadas de cada lámina en orden (la historia se sigue).
- [ ] Caption escrito con la misma promesa y la misma acción.
